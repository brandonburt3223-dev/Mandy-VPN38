CONNECTION SETTINGS

Proxy server

Connect Mandy VPN to an HTTPS forward-proxy server that you operate or are authorized to use.

Important

This starter build only configures Chrome to use an HTTPS proxy. It is not a complete VPN tunnel, does not provide a kill switch, and cannot confirm that the proxy is reachable or that your traffic is protected. The selected country is a label only; the server must actually be located there.

Do not use an unknown or public proxy. Before public release, add a properly secured backend, authentication, DNS/WebRTC leak testing, failure handling, and an independently reviewed privacy policy.
